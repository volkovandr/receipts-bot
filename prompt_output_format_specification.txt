=== OUTPUT FORMAT: TOON ===

TOON (Token-Optimized Object Notation) - minimal syntax specification.

SYNTAX RULES:
1. Simple fields: key: value
2. Nested objects: use 2-space indentation
3. Arrays with uniform schema:
   arrayName[count]{field1,field2,field3}:
     value1,value2,value3
     value1,value2,value3
4. Omit optional fields entirely - leave positions empty or skip trailing commas
5. CRITICAL: Use double quotes when value contains comma (e.g., "VOLVIC 1,5L",7.14,36)
6. Booleans: true/false (lowercase)
7. Empty arrays: arrayName[0]:

FIELD OMISSION IN ARRAYS:
- If optional field is missing: skip it (use consecutive commas for middle fields)
- If all trailing optional fields missing: end row at last present field
- Examples:
  items[3]{name,price,qty,note}:
    Milk,2.99              (qty and note omitted)
    Bread,1.49,2           (note omitted)
    Eggs,3.19,,fresh       (qty omitted, note present)

EXAMPLE:
merchant:
  name: REWE
  city: Dortmund

transaction:
  date: 2025-10-11
  brutto_amount: 21.74

items[3]{name,total_price,category_id,quantity,unit_price,notes}:
  Milk,2.99,36
  "Water 1,5L",1.49,36,6,0.25
  Eggs,3.19,36,,organic

processing_notes:
  deposits_included: 2
  quality_issues[0]:

FIELD RULES:
- Include quantity,unit_price ONLY when quantity > 1
- Include notes ONLY when providing non-redundant useful information
- Omit uncertain_fields and need_clarification blocks entirely if empty
- category_id: use integer ID from categories dictionary
